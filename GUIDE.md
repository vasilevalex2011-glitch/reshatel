# Решатель задач с экрана: гайд

## Как это работает

1. Вы запускаете `Reshatel.exe`: справа на экране появляется окно.
2. Нажимаете **«Выделить область»** (или Ctrl+Shift+S) и мышью обводите задачу на экране.
3. Программа делает снимок и отправляет его в нейросеть, которая работает **на вашем же компьютере** (через программу Ollama). Интернет нужен только один раз, чтобы скачать модель.
4. Выбираете режим:
   - **Простой**: короткое решение и строка «Ответ: ...».
   - **Глубокий**: подробное объяснение каждого шага, проверка и ответ.
5. Решение выводится в окне по мере генерации. Кнопка **«Заново»** решает ту же задачу в другом режиме.

Лимитов нет, оплаты нет, данные никуда не отправляются.

## Что нужно скачать (на каждом компьютере)

| Что | Зачем | Ссылка |
|---|---|---|
| Ollama | запускает нейросеть локально | https://ollama.com/download |
| Модель gemma3:4b или другая | сама нейросеть | https://ollama.com/library/gemma3 |
| Reshatel.exe | наша программа | собираете сами, см. ниже |

Python на компьютерах, где будет работать готовый `.exe`, **не нужен**. Он нужен только для сборки (вариант А).

### Шаг 1. Установить Ollama
1. Скачайте установщик для Windows: https://ollama.com/download
2. Запустите `OllamaSetup.exe` и дождитесь окончания. Ollama остаётся работать в трее и запускается вместе с Windows.

### Шаг 2. Скачать модель
Откройте «Пуск», введите `cmd`, откройте «Командную строку» и выполните одну команду.

Выберите по мощности компьютера:

| Компьютер | Команда | Размер |
|---|---|---|
| Слабый, 8 ГБ ОЗУ, без видеокарты | `ollama pull gemma3:4b` | около 3 ГБ |
| Средний, 16 ГБ ОЗУ или видеокарта от 8 ГБ | `ollama pull qwen2.5vl:7b` | около 6 ГБ |
| Мощный, видеокарта от 12 ГБ | `ollama pull gemma3:12b` | около 8 ГБ |

Страницы моделей: https://ollama.com/library/gemma3 и https://ollama.com/library/qwen2.5vl

Проверка: команда `ollama list` должна показать скачанную модель.

Если выбрали не `gemma3:4b`, впишите имя модели в `config.json` рядом с `Reshatel.exe` (поле `"model"`). Файл появляется после первого запуска.

## Как получить Reshatel.exe

`.exe` собирается под Windows, поэтому его нужно собрать один раз на Windows (или в облаке GitHub). Потом готовый файл можно копировать на любые компьютеры.

### Вариант А. Собрать у себя (нужен Python)
1. Установите Python 3.10 или новее: https://www.python.org/downloads/windows/
   В установщике **обязательно отметьте галочку «Add python.exe to PATH»**.
2. Положите в одну папку файлы `solver.py`, `requirements.txt`, `build.bat`.
3. Дважды щёлкните `build.bat` и подождите 2-5 минут.
4. Готовый файл появится в `dist\Reshatel.exe`.

### Вариант Б. Собрать в облаке (ничего ставить не нужно)
1. Зарегистрируйтесь на https://github.com и создайте репозиторий: https://github.com/new
2. Загрузите в него файлы проекта: на странице репозитория **Add file → Upload files**, перетащите `solver.py`, `requirements.txt` и папку `.github` целиком (внутри `workflows/build.yml`).
3. Откройте вкладку **Actions → Build Windows exe → Run workflow**.
4. Через 3-5 минут откройте завершившийся запуск и в разделе **Artifacts** скачайте `Reshatel-windows`. Внутри лежит `Reshatel.exe`.

Документация PyInstaller: https://pyinstaller.org

## Как перенести на чужой компьютер
1. Скопируйте `Reshatel.exe` (например, на флешку).
2. На том компьютере выполните шаги 1 и 2 выше (Ollama и модель).
3. Запустите `Reshatel.exe`.

При первом запуске Windows может показать синее окно «Windows защитила ваш компьютер». Это происходит со всеми программами без платной цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Антивирус тоже иногда ругается на файлы PyInstaller, это ложное срабатывание: при необходимости добавьте файл в исключения.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| В окне «Не удаётся подключиться к Ollama» | Запустите Ollama из меню «Пуск» и перезапустите программу |
| «Модель не найдена» | Выполните `ollama pull gemma3:4b` (или ту модель, что указана в `config.json`) |
| Ответ идёт очень медленно | Это слабое железо: возьмите модель поменьше или закройте другие программы |
| Модель ошибается в сложной математике | Возьмите модель побольше (`qwen2.5vl:7b`, `gemma3:12b`) и режим «Глубокий» |
| Не работает Ctrl+Shift+S | Горячую клавишу можно сменить в `config.json` (поле `hotkey`), либо пользуйтесь кнопкой |
| Рамка выделения съезжает на экране с масштабом | Перезапустите программу, масштаб Windows 100-150% поддерживается |

Нейросети ошибаются, поэтому важные ответы перепроверяйте. И учтите правила школы, вуза или экзамена: использование таких программ там может быть запрещено.
